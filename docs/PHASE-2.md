# Fase 2 — Institucional

A Fase 2 entrega a camada institucional completa do KZ Tech Site, com conteúdo próprio, navegação dedicada e catálogo completo do KOS do ecossistema.

## Escopo concluído

- Página inicial institucional com proposta de valor, chamadas para portfólio e empresa e apresentação do ecossistema.
- Portfólio completo consumindo o catálogo central.
- catálogo completo do KOS dos 11 produtos registrados no backend, organizado por áreas.
- Página individual para cada produto, com tipo, estágio, propósito, ação de orçamento e produtos relacionados.
- Página institucional da empresa.
- Página Sobre nós.
- Página História.
- Página Visão.
- Página Valores com princípios individuais.
- Página Parcerias.
- Página Carreiras.
- FAQ institucional.
- Página de Contato com formulário integrado à API.
- Páginas legais de Privacidade, Uso e Serviço.
- Rodapé com acesso direto aos documentos legais.
- Navegação por hash compatível com GitHub Pages.
- Conteúdo dinâmico escapado antes de ser inserido no HTML.
- Estados de produto preservados conforme o catálogo central.
- Página de produto inexistente com fallback navegável.
- Cache-busting do JavaScript após a implementação.

## Catálogo institucional

O catálogo atual inclui Korczak AI, MOROK, Korczak IDE, Korczak Workspace, KORCZAK FLOW, KORCZAK DOCUMENTS, KORCZAK VISION, KORCZAK OPS, KORCZAK CONNECT e KORCZAK MOBILE.

## Critério de conclusão

1. Todas as rotas institucionais possuem conteúdo próprio.
2. O catálogo completo do KOS pode ser explorado.
3. Cada produto possui página individual.
4. Contato e documentos legais estão acessíveis.
5. A navegação continua funcionando no GitHub Pages.
6. Nenhuma página depende da API para realizar a primeira renderização.
7. O conteúdo dinâmico é escapado.
8. O frontend passa pela validação automatizada e o Pages publica o commit da fase.
